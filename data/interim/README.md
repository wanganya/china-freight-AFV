# Description of the Interim Data Folder

This folder contains data generated by one stage of the workflow and subsequently consumed by a later stage.

## Structure

- `/freight_od`: Stage 1 expanded intercity freight OD demand.
- `/trajectory_generation`: Stage 2 preprocessed OD data, seasonal constraints, paths, and optimized freight-trip assignments.
- `/distance_correction`: Stage 3 city/time-dependent distance-correction factors.

These files are reproducible from the corresponding input datasets and scripts.
