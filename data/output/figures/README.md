# Description of the Output Figures

This directory stores figures generated by the Stage 4 visualization utilities.

Current figure names include, depending on the available output data:

```text
optimization_history.png
station_distribution.png
charging_post_distribution.png
spare_battery_distribution.png
vehicle_category_distribution.png
vehicle_type_distribution.png
objective_values.png
driving_rest_time.png
energy_refill.png
ghg_emission.png
```

The code creates this directory as:

```text
<output_directory>/figures/
```
