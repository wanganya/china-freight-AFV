# Description of the Output Data Folder

This folder stores the final outputs generated by the Stage 4 simulation-based multi-objective optimization framework.

The current code writes most text/binary results directly under the configured `output_directory`, with additional `/figures`, `/cache`, and `/intermediate` subdirectories.

## Main optimization outputs

```text
optimization_history.csv
best_solution.pkl
best_objectives.csv
pareto_front.csv
pareto_solutions.pkl
best_compromise.json
```

## Main simulation-result outputs

```text
01ElectrifiedVehicle.txt
02Station.txt
03PathExecution.txt
04Objective.txt
05AlgorithmRelated.txt
06ParkingRecord.txt
07DrivingTimeStatistics.txt
08StationServiceRecords.txt
```

## Subdirectories

- `/figures`: visualization outputs generated from optimization/simulation results.
- `/cache`: processed-data and trajectory-index caches.
- `/intermediate`: iteration summaries and optionally serialized intermediate solutions.
